# Сырые исходники корпуса (ручной сбор)

Скрипт `backend/app/ingestion/parse_corpus.py` умеет читать **HTML** (сохранённая
страница браузера, `Cmd+S` → "Страница целиком/Webpage, Complete") или **PDF**
(кнопка экспорта/печати на adilet.zan.kz, если доступна). Он не зависит от точной
вёрстки — просто вытаскивает весь видимый текст и разбирает его по паттернам
`Глава N`, `Статья N`, нумерованные пункты, поэтому подходит любой из двух форматов.

## Что сохранить сюда

Открывайте акт на adilet.zan.kz **в браузере, вручную**, дождитесь полной
загрузки JS-контента, и сохраняйте целиком (не только один экран — прокрутите
весь документ перед сохранением, если сайт подгружает контент по скроллу).

| Файл | Что это | Ожидаемое имя |
|---|---|---|
| Конституция РК | `constitution.html` **или** `constitution.pdf` |
| Трудовой кодекс РК | `labor_code.html` **или** `labor_code.pdf` |

Если сайт разбивает кодекс на отдельные страницы/главы — сохраните каждую
часть как `labor_code_part1.html`, `labor_code_part2.html` и т.д., скрипт
объединит их по алфавитному порядку имён файлов.

## Метаданные редакции

Даты в `meta.json` сверены 28.09.2026 по официальным карточкам «Әділет»:

| Документ | Редакция сохранённого корпуса | Подтверждение |
|---|---|---|
| Конституция РК | Первоначальная редакция, принята 15.03.2026; дата изменения в карточке не указана | [Карточка акта](https://old.adilet.zan.kz/rus/docs/K2600000000/info) |
| Трудовой кодекс РК | 06.09.2026 — дата изменения акта | [Карточка акта](https://old.adilet.zan.kz/rus/docs/K1500000414/info), [история изменений](https://old.adilet.zan.kz/rus/docs/K1500000414/history) |

Оба PDF экспортированы 22.09.2026 (дата создания в PDF). Трудовой кодекс
содержит изменения Закона от 07.07.2026 № 334-VIII, в том числе в статьях
32 и 116. Дата принятия этого закона и дата редакции кодекса — разные даты.
Примечание Конституции о постановлении Конституционного Суда от 07.07.2026
также не является датой изменения Конституции.

При обновлении корпуса сверяйте **сохранённый текст** с разделами «Информация»
и «История изменений». Не подставляйте текущую дату или дату выгрузки вместо
даты редакции. Сохраните ссылку и дату проверки в `meta.json`.

После изменения метаданных обновите JSONL и уже заполненный Qdrant:

```bash
cd backend
.venv/bin/python -m app.ingestion.parse_corpus
.venv/bin/python -m app.retrieval.index_corpus --refresh-sources
```

`--refresh-sources` меняет только поле `source` у существующих фрагментов,
текст и структура которых совпадают с JSONL; векторы не пересчитываются.
При изменении текста нужен обычный запуск индексатора. Режим `--if-empty`
(в том числе при старте Docker) также обновляет метаданные существующего индекса.
Поэтому `get_article` через MCP получает исправленную дату из Qdrant.

Если файла `meta.json` нет — скрипт подставит `"источник не указан"` и выведет
предупреждение.
Незаполненная заглушка в `source_note` останавливает парсер с ошибкой.
